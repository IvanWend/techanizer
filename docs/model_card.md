# Model Card: Techanizer


## Model Details

- **Тип:** LLM-модели и эмбеддинги через стороннего провайдера, вызываются через API; настройка промптом и Pydantic-схемой.
- **Провайдеры:** Alibaba Cloud (DeepSeek V4.1 Flash, GLM 5.3, Qwen 3.8 Flash, text-embedding-v4).
- **Версии:** фиксируются названия моделей; сами модели версионирует провайдер, поэтому результат может меняться между запусками.

| Этап | Модель |
|---|---|
| Извлечение | DeepSeek V4.1 Flash |
| Эмбеддинги | Qwen3 text-embedding-v4 (1024-dim) |
| Агент, стадия 1 | GLM 5.3 |
| Агент, стадия 2 | Qwen 3.8 Flash (EN + RU) |
| LLM-как-судья | GLM 5.3 |


## Inputs / Outputs

| Этап | Вход | Выход |
|---|---|---|
| Извлечение | Очищенный от HTML текст вакансии или комментария | JSON, проверяемый Pydantic-схемой, с полями вакансии и дословными цитатами из исходного текста |
| Эмбеддинги | Заголовок + уровень + стек + описание роли | Вектор 1024 измерения (pgvector) |
| Агент, стадия 1 | Вопрос пользователя + результаты инструментов | Типизированный payload: таблицы, цитаты, факты |
| Агент, стадия 2 | Payload | Текст ответа на языке запроса |


## Quantitative Analysis

Оценка на 40 вакансиях. Эталонная разметка получена GLM 5.3, проверена и отобрана вручную.

| Оценка | Метрика | Результат |
|---|---|---|
| Extraction (40 публикаций) | micro, точное совпадение | 87,3% |
| Grounding (12 598 значений) | дословно | 97% |
| Retrieval (12 запросов) | MRR | 1,00 |
| Retrieval | precision@10 | 0,92 |
| Agent eval | pass rate | 98,3% |

## Considerations

- Данные смещены в сторону стартапов, и не представляют весь рынок труда.
- Зарплата указана примерно у 32% ролей, seniority неизвестен примерно у 43%.
- Провайдер может обновить модель: результаты могут меняться между запусками.
- Модель предназначена для поиска и исследовательской аналитики собранного корпуса вакансий.
