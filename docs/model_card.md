# Model Card: Techanizer


## Model Details

- **Тип:** LLM модели через сторонних провайдеров, вызываются через API; настройка промптом и Pydantic-схемой. Эмбеддинги: предобученная модель `bge-m3`, запускается локально через Ollama.
- **Провайдеры:** DeepSeek (V4 Flash, V4 Pro), Moonshot AI (Kimi K3), BAAI (`bge-m3`).
- **Версии:** фиксируются названия моделей; сами модели версионирует провайдер, поэтому результат может меняться между запусками.

Таблица с описанием этапов и моделей:

| Этап | Модель |
|---|---|
| Extraction | DeepSeek V4 Flash |
| Agent, stage 1 (tool calling) | DeepSeek V4 Pro |
| Agent, stage 2 (prose) | DeepSeek V4 Pro (EN), Kimi K3 (RU) |
| Gold labeler (extraction eval) | DeepSeek V4 Pro |
| Embeddings | bge-m3 |
| LLM as a Judge (agent prose) | Kimi K3 |


## Intended Use

Модель (DeepSeek V4 Flash) предназначена для автоматизированного извлечения структурированных данных из англоязычных и русскоязычных IT-вакансий, собранных из нескольких источников. Результаты используются в Techanizer для:
- унификации и нормализации данных о вакансиях;
- фильтрации и поиска вакансий по навыкам, должностям, уровню, локации и другим параметрам;
- SQL-аналитики собранного корпуса;
- векторного поиска и ответов AI-агента на вопросы пользователей об имеющихся данных.
Модель предназначена для исследовательского анализа собранного корпуса и изучения тенденций внутри него.


## Inputs

**Вход:** очищенный от HTML текст вакансии или комментария с описанием вакансии.

## Outputs

**Выход:** JSON, проверяемый Pydantic-схемой с полями вакансии и фрагменты исходного текста; далее данные нормализуются и сохраняются.


## Quantitative Analysis

Оценка выполнена на 40 публикациях. Золотая разметка получена моделью DeepSeek V4 Pro; оценивается модель DeepSeek V4 Flash. Поля, заполненные непосредственно данными из 4 источников, исключены. Для каждого поля используется свой знаменатель.

| Поле (переменная) | Совпадение с эталонной разметкой |
|---|---:|
| `doc_type` | 100% (40/40) |
| `role-count` | 92,5% (37/40) |
| `seniority` | 94,3% (66/70) |
| `employment_type` | 100% (69/69) |
| `remote_policy` | 93,2% (68/73) |
| `salary_min` / `salary_max` / `currency` | 100% (55/55) |
| `location` | 78,6% (55/70) |
| `company` | 77,8% (28/36) |
| `title` | 72,6% (53/73) |
| `stack` | 55,6% (40/72) |
| `description` | 87% (54/62) |

**Метрика:** точное совпадение с эталонной разметкой; для `stack` сравниваются множества навыков.

**Grounding:** 12 598 извлечённых значений; 97% дословно.

**Agent eval:** 59/60 (детерминированные, семантические, refusal/injection запросы).

**Retrieval:** 12 запросов с эталонной разметкой; mean MRR 0,66, precision@10 0,48. (планируется улучшение метрики за счёт добавления reranker или  hybrid lexical+vector поиска.)

## Considerations

- Данные смещены в сторону стартапов, Hacker News и Web3 и не представляют весь рынок труда.
- Зарплата указана примерно у 32% ролей, seniority неизвестен примерно у 43%. Эти значения не генерируются рандомно.
- Провайдер может обновить модель: результаты могут меняться между запусками.
- Модель предназначена для поиска и исследовательской аналитики собранного корпуса вакансий. Она не предназначена для автоматического отбора кандидатов или выводов обо всём рынке труда.
