# Model Card: Techanizer


## Model Details

- **Тип:** LLM-модели и эмбеддинги через стороннего провайдера, вызываются через API; настройка промптом и Pydantic-схемой.
- **Провайдеры:** Alibaba Cloud Model Studio — DeepSeek V4.1 Flash, GLM 5.3, Qwen 3.8 Flash, text-embedding-v4.
- **Версии:** фиксируются названия моделей; сами модели версионирует провайдер, поэтому результат может меняться между запусками.

Таблица с описанием этапов и моделей:

| Этап | Модель |
|---|---|
| Извлечение | DeepSeek V4.1 Flash |
| Агент, первая стадия (вызов инструментов) | GLM 5.3 |
| Агент, вторая стадия (генерация ответа) | Qwen 3.8 Flash (EN + RU) |
| Эмбеддинги | Qwen3 text-embedding-v4 (1024-dim) |
| LLM-как-судья | GLM 5.3 |


## Intended Use

Модель (DeepSeek V4.1 Flash) предназначена для автоматизированного извлечения структурированных данных из англоязычных и русскоязычных IT-вакансий, собранных из нескольких источников. Результаты используются в Techanizer для:
- унификации и нормализации данных о вакансиях;
- фильтрации и поиска вакансий по навыкам, должностям, уровню, локации и другим параметрам;
- SQL-аналитики собранного корпуса;
- векторного поиска и ответов AI-агента на вопросы пользователей об имеющихся данных.


## Inputs

**Вход:** очищенный от HTML текст вакансии или комментария с описанием вакансии.

## Outputs

**Выход:** JSON, проверяемый Pydantic-схемой с полями вакансии и фрагменты исходного текста; далее данные нормализуются и сохраняются.


## Quantitative Analysis

Оценка выполнена на 40 публикациях. Золотая разметка получена моделью GLM 5.3, проверена и отобрана вручную; оценивается модель DeepSeek V4.1 Flash. Метрика извлечения — точное совпадение (micro) по всем сравнениям значений полей; для `stack` сравниваются множества навыков.

| Оценка | Метрика | Результат |
|---|---|---|
| Извлечение (40 публикаций) | micro, точное совпадение | 87,3% |
| Grounding | дословно (12 598 значений) | 97% |
| Agent eval | pass rate | 59/60 |
| Retrieval (12 запросов, гибрид pgvector + tsvector, RRF) | MRR | 1,00 |
| Retrieval | precision@10 | 0,92 |

## Considerations

- Данные смещены в сторону стартапов, Hacker News и Web3 и не представляют весь рынок труда.
- Зарплата указана примерно у 32% ролей, seniority неизвестен примерно у 43%. Эти значения не генерируются рандомно.
- Провайдер может обновить модель: результаты могут меняться между запусками.
- Модель предназначена для поиска и исследовательской аналитики собранного корпуса вакансий. Она не предназначена для автоматического отбора кандидатов или выводов обо всём рынке труда.
